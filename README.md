# Faraz Learning Project (Kotlin + Jetpack Compose)

A clean, ready-to-build Android Jetpack Compose project for learning Kotlin UI development and building Debug APKs automatically via GitHub Actions.

## Quick Start
1. Edit `app/src/main/kotlin/org/example/App.kt` to experiment with Jetpack Compose UI.
2. Push to `main` (or trigger **Build Android Debug APK** manually in the GitHub **Actions** tab).
3. Download `Faraz-Larza-Player-Debug-APK` from the workflow run artifacts.
